# 3D Physics Sandbox

브라우저에서 별도 빌드 과정 없이 바로 실행되는 1인칭 3D 물리 샌드박스 및 파쿠르 미니게임입니다. 단일 HTML 파일(`3d.html`) 안에 `A-Frame 1.4.2`와 `Cannon.js`(`aframe-physics-system`) 기반의 물리 오브젝트와 절차적 점프맵 코스가 구현되어 있습니다.

## 실행 방법

`3d.html` 파일을 웹 브라우저로 열면 바로 실행됩니다. (외부 CDN에서 A-Frame 및 물리 엔진 스크립트를 불러오므로 인터넷 연결이 필요합니다.)

## 조작키

| 입력 | 동작 |
| :--- | :--- |
| `W` `A` `S` `D` / 방향키 | 이동 |
| `Shift` | 달리기 |
| `Space` | 점프 (떼는 타이밍에 따라 점프 높이 조절) |
| 마우스 좌클릭 | 바라보는 물리 오브젝트 밀쳐내기 (Force Push) |
| `R` | 파쿠르 시작 지점으로 리스폰 |
| `H` | 좌측 조작 안내 및 우측 속도계 HUD 숨기기/표시 |

## 구성 요소

- **물리 샌드박스 구역**: 도미노 라인(150개), 블록 피라미드, 대형 구체 등 마우스 좌클릭 충격량으로 무너뜨릴 수 있는 동적 물리 오브젝트 배치
- **절차적 파쿠르 코스**: 실행할 때마다 일반 발판, 점프 패드(노란색), 대시 패드(초록색), 이동 발판(보라색) 75개가 이어지는 점프 코스와 정상 골인 지점 생성
