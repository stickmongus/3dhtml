# 3D Physics Sandbox

브라우저에서 별도 빌드 과정 없이 바로 실행되는 1인칭 3D 물리 샌드박스 및 파쿠르 미니게임입니다. 단일 HTML 파일(`3d.html`) 안에 `A-Frame 1.4.2`와 `Cannon.js`(`aframe-physics-system`) 기반의 물리 오브젝트와 절차적 점프맵 코스가 구현되어 있습니다.

## 바로 실행

- 웹 플레이: https://stickmongus.github.io/3dhtml/
- 로컬 실행: `3d.html` 파일을 웹 브라우저로 열면 바로 동작합니다. (CDN 스크립트를 불러오므로 인터넷 연결 필요)

## 조작키

| 입력 | 동작 |
| :--- | :--- |
| `W` `A` `S` `D` / 방향키 | 이동 |
| `Shift` | 달리기 |
| `Space` | 점프 (떼는 타이밍에 따라 점프 높이 조절, 코요테 타임·점프 버퍼 적용) |
| `C` | 마지막으로 저장된 체크포인트로 복귀 |
| `R` | 처음 시작 지점으로 코스 및 타이머 초기화 |
| `H` | 좌측 조작 안내 및 우측 속도계 HUD 숨기기/표시 |
| 마우스 좌클릭 | 바라보는 물리 오브젝트 밀쳐내기 (Force Push) |

## 구성 요소

- **물리 샌드박스 구역**: 도미노 라인(150개), 블록 피라미드, 대형 구체 등 마우스 좌클릭 충격량으로 무너뜨릴 수 있는 동적 물리 오브젝트 배치
- **절차적 파쿠르 코스**: 실행할 때마다 일반 발판, 점프 패드(노란색), 다음 발판 방향 대시 패드(초록색), 이동 발판(보라색)으로 구성된 75단계 코스가 생성되며, 15단계마다 자동 체크포인트와 클리어 기록 타이머가 동작합니다.
